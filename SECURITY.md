# Security Policy

## Supported Versions

We only provide security updates for the current major version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for TruthCheck AI. If you discover a security vulnerability within the project, please DO NOT report it by opening a public GitHub issue. 

Instead, please send an email to the security team of Team Xieron. We will prioritize reviewing and addressing the issue. 

When reporting a vulnerability, please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and an assessment of its severity.
- Any proposed solutions or patches, if applicable.

We will acknowledge your report within 48 hours and provide an estimated timeline for the fix. Once the vulnerability is patched, we will publicly acknowledge your contribution (with your permission) in our release notes.
