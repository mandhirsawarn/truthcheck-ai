# Contributing to TruthCheck AI

First off, thank you for considering contributing to TruthCheck AI! It's people like you that make TruthCheck AI such a great tool for digital forensics.

## 🤝 Code of Conduct

By participating in this project, you are expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md). Please report unacceptable behavior to the project maintainers.

## 💡 How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for TruthCheck AI.
- Ensure the bug was not already reported by searching on GitHub under Issues.
- If you're unable to find an open issue addressing the problem, open a new one. Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion for TruthCheck AI, including completely new features and minor improvements to existing functionality.
- Open a new issue with a clear title and description.
- Provide specific examples to demonstrate the steps and the expected behavior.

### Pull Requests
- Fill in the required template.
- Do not include issue numbers in the PR title.
- Include screenshots and animated GIFs in your pull request whenever possible.
- End all files with a newline.
- Make sure your code passes standard linting and formatting.

## 🛠️ Development Setup

1. Fork the repo and create your branch from `main`.
2. Install dependencies for the backend (`requirements.txt`) and frontend (`package.json`).
3. Run the development servers using `run.py`.
4. Ensure any new features are thoroughly tested before opening a PR.

Thanks again for contributing to a safer digital ecosystem!
